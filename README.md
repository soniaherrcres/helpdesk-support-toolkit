# 🛠️ Kit de Herramientas de Soporte y Helpdesk

Utilidades y scripts de automatización orientados a agilizar la labor de los técnicos de soporte técnico de TI (Helpdesk / Field Support), reduciendo el tiempo de resolución de incidencias (*MTTR*) mediante diagnósticos automatizados en equipos cliente.

## 🚀 Funcionalidades Principales
* **Identificación Rápida:** Extracción automática del nombre de equipo, usuario conectado y versión del sistema operativo.
* **Auditoría de Red:** Comprobación de direcciones IP locales y estado de la pasarela de red predeterminada.
* **Test de Conectividad Preventivo:** Validación de respuesta mediante comandos ICMP para descartar cortes de red locales antes de escalar incidencias.

## 📂 Estructura del Repositorio
* `Helpdesk-Diagnostic-Tool.ps1`: Script principal de diagnóstico automatizado para entornos Windows.
